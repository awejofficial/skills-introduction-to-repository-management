# Security Policy

## Supported versions

This project currently supports security fixes on the default branch only.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository:

1. Open the repository on GitHub.
2. Go to the **Security** tab.
3. Select **Report a vulnerability**.
4. Include impact, reproduction steps, and suggested remediation.

Please do **not** open public issues for security vulnerabilities.

## Maintainer response policy

- Acknowledgement target: within 2 school/business days.
- Initial triage target: within 5 school/business days.
- Critical issues involving confidentiality/integrity risks are prioritized immediately.
- Maintainers will coordinate remediation and disclosure timing with the reporter.

## Security update workflow

- Dependency alerts are monitored through GitHub Dependabot alerts.
- Dependency update pull requests are reviewed like any other change.
- Security fixes should include validation notes in the pull request.
