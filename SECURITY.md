# Security Policy

## Supported versions

This project is maintained as a single active branch (`main`) for the GitHub Skills exercise.
Security fixes are applied to `main`.

## Reporting a vulnerability

Please do **not** open public issues for suspected vulnerabilities.

Instead, use GitHub's private vulnerability reporting for this repository:

1. Open the repository on GitHub.
2. Go to **Security** -> **Advisories**.
3. Select **Report a vulnerability** and provide reproduction details.

If private reporting is unavailable in your repository settings, contact maintainers privately through repository administrators and avoid sharing exploit details publicly.

## Maintainer response policy

Maintainers aim to:

- acknowledge a report within **3 business days**,
- provide an initial triage/update within **7 business days**,
- coordinate a fix and disclosure timeline based on severity.

## Dependency security

Dependabot version-update pull requests are configured in `.github/dependabot.yml`.

To fully enable security monitoring, repository administrators should also enable:

- **Dependency graph**,
- **Dependabot alerts**,
- **Dependabot security updates**.

These are GitHub repository settings and are not enabled only by committing configuration files.
